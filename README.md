# 🛒 Marketplace Backend – Clean Architecture

## 📌 Project Description

This project is a backend implementation of a Marketplace system developed using **Clean Architecture** principles.  
It is designed to simulate a real-world e-commerce platform with modular and maintainable structure.

The project was developed as part of academic and self-learning activities to strengthen backend development skills.

---

## ✨ Features

- User registration and authentication  
- Product management system  
- Order processing  
- Layered architecture implementation  
- Repository pattern usage  
- Scalable and maintainable structure  

---

## 🛠 Technologies Used

- C#  
- .NET Core  
- MYSQL Server  
- Entity Framework  
- Clean Architecture    

---

## 🏗 Architecture

This project follows **Clean Architecture** principles:

- **Domain Layer** → Business entities and rules  
- **Application Layer** → Use cases and services  
- **Infrastructure Layer** → Database and external services  
- **Presentation Layer** → API endpoints
